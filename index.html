When a refreshed injury item materially changes fantasy value, DraftPilot now applies the linked downgrade/upgrade directly to recommendations, Model sorting and auction guidance. Season-ending players can be removed from redraft pools while remaining visible in Shaker dynasty.
Freshness note: DraftPilot is a static GitHub Pages app, so the cards above are a dated snapshot rather than a live background feed. The source buttons open the continuously updated pages. This keeps the draft engine fast and avoids the slowness caused by live scraping/API calls. When this snapshot is refreshed, material injury adjustments are updated in the same data block so the draft board changes with the Intel.
